# Тайны Средиземья: Перепутанные судьбы

Небольшая интерактивная логическая головоломка на русском языке. Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Публикация через GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку `main` и папку `/ (root)), затем Save.
4. После публикации сайт будет доступен по адресу `https://eniqq.github.io/middle-earth-mystery/`.

Всё работает в одном HTML-файле, без сборки, библиотек и внешних ресурсов.
